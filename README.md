# Aamir Khan - AI/ML Engineer Portfolio

A modern, premium, fully responsive portfolio website built with React, Vite, and Tailwind CSS.

## Features

- **Modern Tech Stack**: React 18, Vite, Tailwind CSS, Framer Motion
- **Premium Design**: Dark theme, glassmorphism, gradient accents
- **Smooth Animations**: Framer Motion powered scroll animations
- **Interactive Elements**: Particle background, custom cursor glow, hover effects
- **Responsive**: Mobile-first design, works on all devices
- **SEO Optimized**: Meta tags, semantic HTML, fast loading
- **Performance**: Optimized builds, lazy loading, code splitting

## Sections

1. Hero with animated typing effect
2. About with professional summary
3. Skills with categorized cards
4. Experience timeline
5. Projects showcase
6. Education
7. Achievements with counters
8. GitHub activity section
9. Contact form

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

```
src/
├── assets/          # Static assets
├── components/      # Reusable UI components
├── sections/        # Page sections
├── layouts/         # Layout components (Navbar, Footer)
├── hooks/           # Custom React hooks
├── animations/      # Animation variants
├── data/            # Portfolio data
├── styles/          # Global styles
├── App.jsx          # Main app component
└── main.jsx         # Entry point
```
